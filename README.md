SAT League Assistant
A personal, non-commercial analysis tool for one private Yahoo Fantasy Basketball league. It reads league data through the Yahoo Fantasy Sports API so the owner no longer has to copy numbers from screenshots.
Read-only · Single league · One user · Runs locally

At a glance
	
Type	Personal hobby project. No company product, no monetization, not distributed.
League	One private Yahoo Fantasy Basketball league (ID 242788): 10 teams, head-to-head, 9 categories
Users	One: the league member who owns the Yahoo account
Access	Read-only (Fantasy Sports Read). No write access requested.
Volume	A few dozen requests per day at most, mainly one pull each morning
Where it runs	A script on the owner's own computer
What it does
Projects weekly head-to-head matchups by category
Helps with daily lineup and injured-list decisions
Ranks free agents and waiver pickups for the week ahead
Evaluates trade offers by simulating the rest of the season
Yahoo data it reads
League settings, scoring categories and schedule
Team rosters for the 10 teams in the league
Weekly matchup scores and category totals
Player stats, injury status and free-agent lists
League transactions (adds, drops, trades)
Data handling
Data stays on the owner's computer and is used only for this league
Nothing is shared, sold, published or shown to other users
Credentials are stored locally in a private file and never shared or committed to this repository
